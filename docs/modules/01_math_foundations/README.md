# Module 1: Math Foundations

Module 1 establishes the first-principles mathematical foundation that powers all modern robot kinematics, control systems, and machine learning architectures.

---

## Module Overview

This module bridges linear algebra, topology, and multivariable calculus directly to real-world engineering mechanisms:

1. **Vectors, Basis Spaces & Matrix Transformations:** Understanding 2D transformations as coordinate space warping, area scaling determinants, and field-oriented swerve rotation matrices.
2. **Trigonometry, atan2 & Continuous Angle Topology:** Resolving 4-quadrant heading angles without quadrant ambiguity and optimizing swerve module turning to prevent catastrophic multi-revolution spins.
3. **Single-Variable Motion Calculus & Jerk:** Rates of change from position to jerk, S-curve vs trapezoidal trajectory generation, and numerical integration accuracy.
4. **Multivariable Calculus, Gradients & The Chain Rule:** Partial derivatives, steepest ascent proofs, potential field robot obstacle avoidance, and backpropagation chain rule mechanics.
