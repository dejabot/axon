# Module 2: Machine Learning
Module 2 demystifies deep learning from the ground up, moving from loss landscapes and optimization mathematics to non-linear activations and vector backpropagation engines.

---

## Module Overview
1. **Loss Landscapes & Optimization Algorithms:** Objective surfaces (MSE, Cross-Entropy), learning rates, momentum dynamics, and Adam adaptive optimizer mathematics.
2. **Dense Layers & Non-Linear Activation Functions:** Matrix affine transformations, non-linear mapping (ReLU, GELU, Sigmoid), and the mathematical proof of why deep linear networks collapse into a single layer without activations.
3. **Vector Calculus Backpropagation & Computation Graphs:** Step-by-step derivation of layer error vectors and weight gradients, paired with a from-scratch Python autograd engine.
4. **In-Browser 2D Neural Classifier Sandbox:** Real-time in-browser neural network training with interactive non-linear decision boundary warping.
