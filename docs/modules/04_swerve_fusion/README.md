# Module 4: Swerve & Sensor Fusion
Module 4 covers multi-directional swerve kinematics, geometric module optimization, high-speed skew compensation, AprilTag computer vision, and Extended Kalman Filter (EKF) sensor fusion.

---

## Module Overview
1. **4-Wheel Swerve Kinematics & Vector Decomposition:** ChassisSpeeds vector decomposition to 4 independent swerve module velocities and azimuth steering angles.
2. **Module Optimization & 2nd-Order Skew Correction:** Eliminating 340-degree spin traps and matrix exponential twist discretization to prevent high-speed curved drift.
3. **Computer Vision & AprilTag Perspective-n-Point (PnP):** Pinhole camera models, intrinsic calibration matrices, and solving 3D robot spatial pose from 2D pixel coordinates.
4. **Extended Kalman Filter (EKF) Sensor Fusion:** Optimal statistical fusion of high-frequency (250 Hz) noisy wheel odometry with low-frequency (30 Hz) vision pose estimates.
