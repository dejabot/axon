# Axon: Applied Math, Physics, ML & Autonomous Robotics

Axon is a self-contained, first-principles curriculum designed to build mastery in applied linear algebra, trigonometry, calculus, actuator physics, classical and modern control theory, deep learning, reinforcement learning, and autonomous robotics.

---

## Structure: Modules & Concepts

The curriculum is organized into 5 domain modules containing 25 focused concepts:
1. **Module 1: Math Foundations** (Concepts 01–04)
2. **Module 2: Machine Learning** (Concepts 05–08)
3. **Module 3: Control & Physics** (Concepts 09–12)
4. **Module 4: Swerve & Sensor Fusion** (Concepts 13–16)
5. **Module 5: Reinforcement Learning & Agents** (Concepts 17–25)

Every concept is colocated under `docs/modules/` with:
* A long-form conceptual guide (`README.md`) with first-principles derivations and zero black boxes.
* A companion standalone interactive visualizer (`demo.html`) with Dark/Light theme toggling and touch support.
* From-scratch Python implementations comparing naive failure modes with robust formulations.
